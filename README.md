# account-book-license

가계부 도구의 **라이선스 폐기 목록(CRL)** 을 GitHub Raw로 호스팅하는 산출물 전용 저장소.

## CRL이란

가계부 HTML이 라이선스 토큰을 검증할 때, 환불·유출·재발급 등으로 폐기된 라이선스 ID 목록을 외부에서 보조 검증하는 메커니즘이다. 인터넷이 가능할 때만 동작하며, 오프라인 사용자에게는 적용되지 않는다.

## 파일

- `crl.json` — 폐기된 라이선스 ID 목록 + 발행 시각 + 서명 키 ID
- `crl.sig`  — `crl.json` raw 바이트에 대한 Ed25519 서명 (base64url, 패딩 없음)

## 운영 정책

산출물 전용 저장소다. 외부 PR·이슈는 받지 않는다. 두 파일은 운영자가 격리된 환경에서 도구로만 갱신해 같은 커밋으로 push한다.
